# 千牛商品自动录入工具

## 桌面版一键打包

双击项目根目录的 `一键打包.bat`，会从当前源码重新构建前端、桌面程序和离线安装包。完成后安装包位于 `dist/千牛自动上架-Setup.exe`，解压版位于 `dist/千牛自动上架/`。打包前请关闭正在运行的 `dist/千牛自动上架/千牛自动上架.exe`。命令行运行 `一键打包.bat -AppOnly` 可只生成解压版。

日常只改程序代码、前端或模板时，双击 `一键增量打包.bat`，生成 `dist/千牛自动上架-Update.exe`。更新包不含 Chromium、WebView2、Node.js 和 Playwright 运行时，只能安装到已有完整版本的目录；更新器会优先从卸载注册表自动识别已安装目录并直接更新，识别不到时才显示目录选择页。更新器会在开始替换文件前关闭千牛进程树，并在需要时请求管理员权限；如果 Qt DLL 仍被系统进程占用，会登记为重启替换，按提示重启后完成更新。首次安装或升级这些运行时时，仍使用完整安装包。

当前版本完成了 Excel 模板、字段说明、本地校验，以及基于已登录 Chrome 的网页填写。默认 dry-run，不会点击“提交宝贝信息”。

## 入库与 SKU 图片（正式入口）

桌面版「执行入库」支持搜索主图、商品规格图或两者同时处理。两者同时选择时，先保存并核验商品规格图，再通过官方素材批量导入处理搜索主图：

- 打开软件 → 导入商品清单或选择工作空间 → 执行入库页勾选「确认提交到仓库」→ 点击「入库」。
- 设置页的「SKU 图片处理方式」可多选，至少保留一项；现有默认设置仍为搜索主图。
- 「SKU搜索主图」与「商品规格」是不同字段；搜索主图存在不能通过规格图核验，旧的搜索主图完成记录必须重新核验。
- 每个商品串行完成；已有商品按原 ID 补缺失图片并分别核验，不重复建品，不删除已有搜索主图。
- 执行明细中新增「入库状态」与「图片状态」，区分部分完成与完整核验。

### 规格图入库后分批补传

选择「商品规格图（原方式）」时，商品先不带规格图完成入库，拿到商品 ID 后再进入商品编辑页补传规格图，降低一次性上传触发滑块验证的概率：

- 设置页可配置「每批上传规格图数量」（默认 2，0 表示全部一次上传）；该配置仅在勾选「商品规格图（原方式）」时显示。
- 每批流程：重开编辑页 → 只补本批缺失行 → 保存商品 → 退出编辑页 → 下一批；已保存的行从服务器状态读取，中断后可按缺失行续传，已上传到图片空间的文件不重复上传。
- 每批保存前后会更新「图片状态」；遇到滑块验证仍暂停并保留现场，人工处理后继续，不会自动重复提交。

独立命令行入口 python -m web_fill.material_flow 仅保留为开发调试用途，不是正式工作流。

## 清单同步与执行历史

- 工作空间的 `商品清单.xlsx` 以商品文件夹为镜像：「扫描更新」和「校验」都会先重新扫描工作空间——新增文件夹生成新行，被删除或替换的文件夹对应旧行自动移除，提示「新增/移除 N 款」。
- 图片包路径指向工作空间之外的行视为手工维护，重扫不会移除。
- 被移除商品的执行状态（淘宝商品 ID、入库进度）归档在执行历史中，不会丢失；文件夹重新出现时自动回贴，不重复入库。同一文件夹被换成新商品（图片内容指纹变化）时不回贴，避免漏上架。
- 商品明细里的「清除执行状态」会同时删除对应执行历史，下次校验不会被重新回贴。

## 文件

- `outputs/千牛商品清单模板.xlsx`：商品清单模板，包含 `商品清单`、`字段说明`、`处理日志`。
- `千牛自动上架.py`：读取模板并校验；`--submit` 时连接千牛窗口填写。
- `千牛网页执行.py`：调用项目里已有的 Playwright CLI（与 Codex 同一套），连接 `9222` 已登录 Chrome，只走新建发布页，固定放入仓库。
- `启动持久化千牛.cmd`：独立启动已登录 Chrome，并打开 `9222` 调试端口。

## 使用

先启动已登录窗口（只需一次，之后复用同一 profile）：

```powershell
.\启动持久化千牛.cmd
```

本地校验：

```powershell
python 千牛自动上架.py outputs/千牛商品清单模板.xlsx
```

检查浏览器登录态，不填写商品：

```powershell
python 千牛网页执行.py --probe
```

填写真实商品（仍不点击提交）：

```powershell
python 千牛自动上架.py 你的真实商品.xlsx --submit --limit 1
```

确认页面已选“放入仓库”后，才允许真正提交：

```powershell
python 千牛自动上架.py 你的真实商品.xlsx --submit --confirm-submit --limit 1
```

结果默认另存为带时间戳的 Excel 和 JSON，不修改输入文件。退出码：0 校验/填写通过、1 数据或执行失败、2 读取/保存失败。`--confirm-submit` 只会点击“提交宝贝信息”，不会选择立刻上架。模板里的示例行会被拒绝执行。

安装依赖：`python -m pip install -r requirements.txt`。运行测试：`python -m unittest -v test_validation test_web`。

网页操作使用 Node Playwright CLI（`.work/node_modules/playwright-core`），不安装 Python `playwright` 包。当前没有控制面板，也还没有仓库回查验收。多规格 SKU 表会暂停给人工核对。浏览器连接状态见 `开发进展.md`。
