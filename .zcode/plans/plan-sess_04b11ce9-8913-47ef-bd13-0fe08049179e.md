# 发码工具可视化程序方案（exe + 源码启动 bat 双通道）

## 目标
发码变成"双击图标"：一个独立 exe（日常用，无需装 Python）+ 一个像 `启动测试.bat` 一样的源码启动 bat（改完代码直接点，方便调试）。两者打开同一个图形界面。

## 改动内容

### 1. 升级 `tools/license_keygen.py` 的图形界面
- **首次运行向导**：检测不到私钥时，在窗口内引导"生成新私钥 / 导入备份私钥"（不再依赖命令行报错）；生成后弹窗显示公钥 + 一键复制 + 提示（填入 `desktop/license.py` 后重新打包软件才生效）。
- **常用天数下拉**：永久 / 30 / 90 / 180 / 365（可手输任意天数）。
- **最近签发展示**：窗口内显示最近 8 条流水（时间/机器码/备注/永久或到期），发码后自动刷新；加"打开流水文件夹"按钮。
- **窗口化适配**：无控制台运行时所有错误（私钥缺失/损坏、机器码格式错）改为弹窗提示。
- 命令行模式（generate-keys / issue / gui / selftest）保持原样。

### 2. 新增 `发码工具.bat`（源码启动，仿 `启动测试.bat`）
- Python 查找顺序与 `启动测试.bat` 完全一致（QIANNIU_PYTHON → E:\python → E:\anaconda3 → where python）；
- 提示"使用源码启动发码工具（改完代码直接点这个，不用重新打包 exe）"；
- 运行 `"%PY%" tools\license_keygen.py gui`，出错 `pause` 保留窗口看报错。

### 3. 打包独立程序
- 新增 `tools/keygen.spec`（PyInstaller 6.22.3，onefile + windowed + 应用图标，与主程序同一构建环境）；
- 产出 `dist\千牛发码工具.exe`：双击即用、无需 Python；**私钥不打包进 exe**（运行时从 `%USERPROFILE%\.qianniu-license\private.key` 读取），exe 被拷走也无法发码。

### 4. 验证
- `selftest` 全量回归（RFC 8032 向量等）+ exe 以 selftest 参数冒烟（退出码 0）；
- 分别启动 bat 与 exe 的 GUI，确认窗口存活后保留打开供你试用。

### 5. 文档
- 更新《发码与激活指南.md》：两条启动路径（bat=源码调试、exe=日常）+ exe 重新打包命令（`python -m PyInstaller tools/keygen.spec`）。
